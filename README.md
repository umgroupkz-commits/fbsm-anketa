# Анкета стажёра FBSM

Страница, по которой новый сотрудник сам сдаёт документы для оформления.
Личная ссылка лежит в карточке «Поиск/Приём/Стажировка» (поле «Ссылка для
сотрудника»), HR отправляет её стажёру. Данные и файлы уходят функции
`anketa` (Supabase), а она пишет их в поля карточки Битрикс24.

Секретов здесь нет: страница знает только адрес функции, а доступ к карточке
даёт личный код в ссылке.
